# Дневник

Личный дневник для iPad и iPhone: запись дня, настроение по шкале 1–7, фото, видео и голос, поиск и аналитика по годам. Работает без интернета, записи хранятся только на устройстве.

- Установка: открыть адрес сайта в Safari → «Поделиться» → «На экран „Домой“».
- ТЗ — `SPEC.md`, правила для Codex — `AGENTS.md`.
