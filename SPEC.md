# ТЗ: личный дневник (PWA для iPad и iPhone)

Версия ТЗ от 14 октября 2026. Текущая реализация v1.0.0 — в `index.html`; правила работы с кодом — в `AGENTS.md`.

## 1. Назначение и рамки

Офлайн-дневник для iPhone и iPad: одна запись на день с настроением по шкале 1–7, эмоциями, фото, видео и голосом, быстрый поиск старых записей, аналитика по годам и ежедневные воспоминания.

- **Платформа:** PWA (веб-приложение), ставится из Safari через «Поделиться» → «На экран „Домой“». Хостинг — GitHub Pages (https). Без сервера и аккаунтов: данные хранятся только на устройстве.
- **Пользователь:** один человек, два устройства (iPhone и iPad). Связь между ними — перенос файлом с объединением записей.
- **Язык интерфейса:** русский.

Ограничения iOS, которые реализация обязана учитывать:

- PWA не умеет ставить локальные уведомления по расписанию, а Web Push требует сервера. В v1 ежедневное напоминание делается средствами iOS («Напоминания» или «Команды»), а воспоминание дня показывается при открытии приложения.
- У приложения на экране «Домой» своё хранилище, отдельное от вкладки Safari. Удаление иконки стирает данные — поэтому резервные копии обязательны.
- Safari при выборе видео может перекодировать ролик. Объём хранилища ограничен свободным местом устройства — приложение показывает, сколько занято.

## 2. Технические требования

Чистые HTML, CSS и JavaScript без фреймворков, сборки, CDN и внешних шрифтов: всё приложение — в одном `index.html`.

- **Файлы — только в корне, без папок** (с iPad в GitHub загружаются отдельные файлы): `index.html`, `manifest.webmanifest`, `sw.js`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `favicon-32.png`, а также `SPEC.md` и `AGENTS.md` (их не кешировать). Все пути относительные, без `/` в начале.
- **Офлайн:** service worker кеширует все файлы приложения; страница — сначала сеть с таймаутом 3 с, остальное — сначала кеш. При новой версии — баннер «Доступна новая версия» с кнопкой «Обновить». При любом изменении файлов поднимать `CACHE` в `sw.js` и `APP_VERSION` в `index.html`.
- **Хранилище:** IndexedDB, база `diary`. Структура базы версионируется (`DB_VERSION`, `onupgradeneeded`), форма данных — через `schemaVersion` в `meta` и функцию `migrateData()`. Старые данные пользователя при обновлении не теряются никогда.
- **Демо-режим:** отдельная база `diary-demo` с примерами за 3 года; настоящие записи не затрагиваются.
- **Сохранение** — сразу при изменении (задержка не более 500 мс) и принудительно при уходе приложения в фон.
- При запуске вызывать `navigator.storage.persist()`.
- **Даты** — локальные строки `YYYY-MM-DD`, никогда через `toISOString()` (иначе сдвиг из-за UTC+3). Настройка «Новый день начинается в» 00, 03, 04 или 05 ч, по умолчанию 04:00 — запись после полуночи относится к прошедшему дню.
- **Поддержка:** Safari на iOS/iPadOS 16.4+, ширина 320–1366 px, обе ориентации, Split View, светлая и тёмная тема.

## 3. Модель данных

Пять хранилищ IndexedDB; записи целиком загружаются в память при старте (10 лет ≈ 3 650 записей), медиа — лениво по id.

| Хранилище | Ключ | Поля |
| --- | --- | --- |
| `entries` | `id` | `id`, `date` (YYYY-MM-DD, индекс; одна запись на дату), `title` («Главное за день», до 120 символов), `text`, `mood` (1–7 или null), `emotions[]`, `tags[]`, `people[]`, `factors[]` (id факторов), `sleep` (часы или null), `media[]` (`{id, kind, duration}` — лента показывает значки, не читая файлы), `favorite`, `milestone`, `createdAt`, `updatedAt` (мс) |
| `media` | `id` | `id`, `entryId`, `kind` (photo, video, audio), `mime`, `blob`, `width`, `height`, `duration` (с), `size`, `createdAt` |
| `thumbs` | `id` (= id медиа) | `blob` — JPEG до 480 px |
| `meta` | `key` | `settings` (PIN-хеш и соль, автоблокировка, начало дня, списки эмоций и факторов), `state` (`lastTransferAt`, `lastBackupAt`, `backupSnoozeUntil`), `schemaVersion` |
| `tombstones` | `id` | `id` удалённой записи или медиа, `kind`, `deletedAt` — чтобы импорт не возвращал удалённое |

- Фото перед сохранением уменьшаются до 2048 px по длинной стороне, JPEG 0,85 (оригиналы остаются в «Фото»).
- Видео хранится как выбрано; при размере больше 200 МБ — предупреждение. Голос — `audio/mp4` (AAC), на других браузерах — что поддерживает `MediaRecorder`.
- Хештеги из текста (`#отпуск`) автоматически добавляются в `tags`.
- Пустая запись (нет текста, «главного», настроения и медиа) при закрытии редактора удаляется.

## 4. Экраны и навигация

Четыре вкладки и настройки: на iPhone и узком экране — нижняя панель вкладок, на iPad шире 900 px — боковая панель слева.

1. **Сегодня** — дата и день недели, серия дней подряд, быстрая отметка настроения (7 смайликов: одно касание создаёт или обновляет запись дня), кнопка «Написать о дне» или превью сегодняшней записи, карточки воспоминаний, полоса настроения за последние 14 дней.
2. **Записи** — лента по месяцам, новые сверху; поиск, фильтры и сегменты «Все / Избранное / Вехи». Карточка записи: дата, день недели, смайлик, «главное» или первые 2 строки текста, до 3 миниатюр, значки видео и голоса.
3. **Календарь** — год из 12 мини-месяцев, каждый день окрашен цветом настроения («год в пикселях»); переключатель года; касание дня открывает запись или создаёт запись на эту дату.
4. **Аналитика** — раздел 8.
5. **Настройки** (шестерёнка) — PIN-код, начало дня, списки эмоций и факторов, инструкция по напоминанию, перенос между устройствами, резервные копии, занятое место, демо-режим, версия.

**Просмотр записи** — полноэкранный лист поверх вкладки: дата, настроение, эмоции, «главное», текст, галерея медиа, теги, люди, факторы и сон; кнопки «Изменить», звезда, флажок вехи, «Удалить». Медиа открываются на весь экран с листанием «назад / вперёд».

## 5. Запись дня

Одна запись на календарный день, её можно дополнять в течение дня; поля в редакторе идут в порядке: дата, настроение, эмоции, «главное за день», текст, медиа, теги, люди, факторы и сон, избранное и веха.

| Оценка | Смайлик | Подпись | Цвет |
| --- | --- | --- | --- |
| 1 | 😭 | Ужасно | тёмно-синий |
| 2 | 😢 | Плохо | синий |
| 3 | 🙁 | Так себе | голубой |
| 4 | 😐 | Нормально | нейтральный серо-песочный |
| 5 | 🙂 | Хорошо | светло-золотой |
| 6 | 😄 | Отлично | золотой |
| 7 | 🤩 | Восторг | тёмно-золотой |

- **Настроение:** 7 крупных кнопок-смайликов в ряд, выбранный подсвечен и подписан; повторное касание снимает оценку.
- **Эмоции:** чипы с множественным выбором. По умолчанию: Радость, Спокойствие, Благодарность, Любовь, Гордость, Интерес, Вдохновение, Усталость, Тревога, Грусть, Раздражение, Злость, Одиночество, Скука, Стресс. Список правится в настройках.
- **Дата** меняется в редакторе; если на новую дату уже есть запись — предложить объединить.
- **Фото и видео:** одна кнопка, `<input type=file accept="image/*,video/*" multiple>`. Для видео — кадр-превью и длительность.
- **Голос:** запись через `MediaRecorder` с таймером и кнопкой «Стоп», лимит 15 минут, плеер прямо в записи. Без доступа к микрофону — понятное сообщение.
- **Теги и люди:** поле с чипами и подсказками из ранее использованных значений.
- **Факторы дня:** переключаемые чипы, по умолчанию: Спорт, Прогулка, Переработка, Выходной, Друзья, Семья, Поездка, Болел, Алкоголь, Экран допоздна; список правится в настройках. Отдельно — «Сон, ч» со степпером по 0,5 ч.
- **Избранное** (звезда) и **веха** (флажок; название вехи — поле «главное за день»).
- **Автосохранение:** запись создаётся при первом заполненном поле, кнопки «Сохранить» нет.

## 6. Поиск и фильтры

Старую запись находим за 2–3 касания: строка поиска плюс фильтры, всё работает офлайн по данным в памяти.

- **Поиск** по тексту, «главному», тегам и людям; регистр и буквы ё/е не различаются; совпадения подсвечиваются в карточках.
- **Фильтры:** год, диапазон настроения, эмоция, тег, человек, фактор, только с медиа, избранное, вехи. Активные фильтры показываются чипами с крестиком, рядом — число найденных записей.
- **Переход к дате** — кнопка с выбором даты.
- **Скорость:** на 3 650 записях поиск отвечает быстрее 200 мс; лента дорисовывается порциями.

## 7. Воспоминания и напоминания

На экране «Сегодня» каждый день — две карточки воспоминаний; само ежедневное оповещение в v1 даёт iOS.

- **«В этот день»:** записи с той же датой прошлых лет, подпись «1 год назад», «3 года назад»; тезис — «главное за день», а если его нет — первое предложение текста до 160 символов; первое фото и смайлик.
- **«Светлое воспоминание»:** случайная запись с настроением 5–7 старше 7 дней. Выбор стабилен в течение дня (зерно — сегодняшняя дата), кнопка «Другое» показывает следующее.
- Касание карточки открывает запись. Если подходящих записей нет — короткое пояснение, что появится здесь со временем.
- **Ежедневное напоминание (v1):** в настройках — инструкция: повторяющееся напоминание в «Напоминаниях» или автоматизация «Команды» → «Время суток» → «Показать уведомление». Автоматизация не должна открывать адрес приложения: он откроется во вкладке Safari с отдельным пустым хранилищем.
- **Напоминание о копии:** если резервной копии не было больше 30 дней — баннер на «Сегодня».

## 8. Аналитика

Аналитика строится за выбранный год или за все годы сразу; все графики — свой SVG без библиотек, цвет всегда дублируется смайликом или числом.

- **Период:** чипы по годам и «Все годы».
- **Сводка:** записей; дней с записью, % от года; среднее настроение; текущая и рекордная серия дней подряд; фото, видео и голосовых; слов.
- **Графики за год:**
    1. Среднее настроение по месяцам: линия выбранного года и тонкие линии прошлых лет — сравнение лет.
    2. Распределение оценок 1–7 — столбцы в цветах шкалы.
    3. Среднее настроение по дням недели.
    4. Влияние факторов, тегов и людей: разница среднего настроения в дни «с» и «без», только при 3 и более днях; горизонтальные столбцы от нуля, по убыванию.
    5. Сон: среднее настроение при сне менее 6, 6–7, 7–8 и от 8 часов.
    6. Частота эмоций.
- **«Все годы»:** среднее настроение и число записей по годам.
- **Итоги года:** 5 лучших и 5 трудных дней с тезисами (касание открывает запись), вехи года, самые частые теги, люди и эмоции.
- **Серия дней:** текущая серия считается от сегодня, а если сегодня записи ещё нет — от вчера (серия «не сгорает» до конца дня).

## 9. Защита PIN-кодом

PIN из 4 цифр закрывает дневник от посторонних глаз при запуске и при возврате из фона; данные на устройстве при этом не шифруются — это честно пишем в настройках.

- Включается в настройках: ввод кода дважды. Хранится только SHA-256 от «соль + PIN» через `crypto.subtle`, соль — 16 случайных байт.
- Автоблокировка: сразу, через 1, 5 или 15 минут в фоне; по умолчанию — 1 минута.
- При уходе в фон содержимое закрывается вуалью, чтобы записи не попадали в переключатель приложений.
- Экран блокировки: цифровая клавиатура 3 × 4 с крупными кнопками; неверный код — анимация «встряхивания»; после 5 ошибок — пауза 30 секунд.
- Забытый PIN сбрасывается только вместе с удалением всех данных, после двойного подтверждения — поэтому важны резервные копии.

## 10. Перенос между устройствами и резервные копии

Перенос и резервная копия — один и тот же ZIP-файл; импорт всегда объединяет записи и никогда не затирает их, поэтому повторный импорт безопасен.

- **Формат:** ZIP без сжатия (stored) с `data.json`, `media/<id>.<ext>` и `thumbs/<id>.jpg`; имя `diary-YYYY-MM-DD.zip`. Запись и чтение ZIP — свой код с CRC32, без библиотек; медиа читаются из архива через `File.slice()`, без загрузки всего файла в память. Пересжатый архив (deflate) читается через `DecompressionStream`, если он есть.
- **`data.json`:** `{ app: "diary", format: 1, schemaVersion, exportedAt, since, entries, media (без blob), tombstones, settings }`; PIN в копию не попадает.
- **Экспорт:** «Полная копия» или «Изменения с даты» (по умолчанию — дата последнего переноса), галочка «С фото, видео и голосом». Архив собирается, затем отдельной кнопкой отдаётся через `navigator.share` → «Сохранить в Файлы» или AirDrop (iOS требует свежего касания для share); запасной вариант — скачивание.
- **Импорт:** выбор `.zip` (или `.json` без медиа), после — отчёт: добавлено, обновлено, объединено записей, добавлено медиа; если ничего не изменилось — так и сказать.

| Ситуация при импорте | Результат |
| --- | --- |
| Записи нет на устройстве | Добавить |
| Тот же `id` | Остаётся версия с более поздним `updatedAt`; медиа объединяются |
| Разные `id`, одна дата | Одна запись: тексты через разделитель (если один содержит другой — берётся длинный), списки объединяются, настроение — из более поздней, звезда и веха — если стоят хотя бы в одной. Считается «объединённой», только если что-то реально изменилось |
| `id` есть среди удалённых в файле | Удалить локально, если локальная правка старше `deletedAt` |
| Медиа с тем же `id` уже есть | Пропустить |

## 11. Дизайн и UX для iPad и iPhone

Спокойный «бумажный» дневник: светлый холодный фон, заголовки системным serif (New York через `ui-serif`), текст — системный шрифт; главное действие — отметить настроение — в одно касание. На «Сегодня» фон-«небо» плавно перекрашивается в цвет выбранного настроения.

- Цвета настроения — шкала от синего через нейтральный к золотому, различимы в обеих темах и при дальтонизме; рядом всегда смайлик или число.
- Цели касания от 44 pt, смайлики настроения от 44 pt (на экранах уже 360 px — чуть меньше, чтобы ряд помещался), поля ввода от 16 px (иначе Safari увеличивает страницу), отступы под safe-area, высота через `100dvh`.
- С «Сегодня»: настроение — 1 касание, начать писать — 2.
- На iPad текст записи не шире 720 px; на широком экране аналитика — в две колонки.
- Пустые состояния объясняют, с чего начать; демо-режим позволяет посмотреть аналитику до появления своих записей.
- Доступность: `aria-label` у смайликов («Настроение 5 из 7 — хорошо»), контраст текста не ниже AA.

## 12. Критерии приёмки

Версия принимается, когда на реальных iPhone и iPad выполнены все пункты.

- [ ] Ставится иконкой из Safari, открывается без панели браузера и работает в авиарежиме.
- [ ] Настроение с «Сегодня» отмечается одним касанием и сохраняется после перезапуска.
- [ ] Запись с 3 фото, 1 видео и голосовой заметкой сохраняется и открывается после перезапуска.
- [ ] Поиск по слову находит запись трёхлетней давности; фильтры по тегу и настроению работают вместе с поиском.
- [ ] Календарь года окрашен по настроению, касание дня открывает запись.
- [ ] Аналитика строится на демо-данных за 3 года без ошибок, сравнение лет видно на графике.
- [ ] «В этот день» показывает записи прошлых лет.
- [ ] Экспорт → импорт на другом устройстве даёт те же записи и медиа; повторный импорт не создаёт дублей.
- [ ] PIN запрашивается при запуске и после фона дольше заданного времени.
- [ ] Вёрстка не ломается при ширине 320 px и в альбомной ориентации, тёмная тема читается.
- [ ] После выкладки новой версии появляется баннер «Доступна новая версия», данные сохраняются.

## 13. На следующие версии

В v1 не входит; порядок — по ценности.

1. Ежедневный push по расписанию через бесплатный воркер (Cloudflare Workers + VAPID) — уведомление без текста записей.
2. Шифрование базы и копий паролем (AES-GCM, ключ через PBKDF2).
3. «Книга года» — экспорт года с фото в PDF.
4. Шаблоны записей и вопрос дня.
5. Место и погода к записи.
6. Несколько записей в день.
7. Учитывать удаление записи, слитой по дате с записью другого устройства (сейчас удаление такой «склеенной» записи на одном устройстве не удаляет её на другом).
